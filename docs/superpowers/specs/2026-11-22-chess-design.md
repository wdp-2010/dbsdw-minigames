# Chess — Design

- **Date:** 2026-11-22
- **Status:** built on branch `chess`; the owner asked to build after the conversation below
  (no separate written approval of this document)

## 1. Intent

A second minigame for the DBSDW minigame server: chess on a giant board, played from above. Players
look at a piece and click; the piece lifts and the squares it can go to light up for them. Two
owner wishes shape the rest:

- **Fresh board per game.** Each game gets its own copy of the board map, built when the game starts
  and removed when it ends, so several games (default 5) run at once.
- **Leaving saves, any game can be continued.** Every move is saved; a game that stops without a
  result can be continued later from a menu.

## 2. Rules for stopping a game (owner approved Claude's proposal)

| Situation | What happens |
|-----------|--------------|
| Both press **Pauzeren** (one asks, the other agrees within 30 s) | Saved, both clocks stop, no result |
| A player leaves (quit, crash, `/leave`) | Board stays, clocks stop; they have 2 minutes to rejoin and are put straight back |
| Still gone after 2 minutes | The player who stayed picks **Winst claimen** (win/loss) or **Bewaren** (saved, no result) |
| Both gone | Saved, no result |
| Server restart | Saved, no result for anyone |
| Unfinished game not played for 14 days | Deleted, no result |
| 5 unfinished games | No new game until one is continued or deleted |

Pauses and expired games count nothing in the stats (not even a played match). All numbers are in
`plugins/Chess/config.yml`.

## 3. Approaches

**Board copies** (picked: template arena with copies, in MinigameCore)

1. *Template + copies (picked).* An arena saved with `copies: N` is a template. The pool hands out a
   free copy per match; the core reads the template's blocks with Paper's structure API, places them
   east of it (`arenas.copy-spacing`, 512 blocks apart: the owner saw neighbouring maps at 80 and
   preferred distance over walls), and when the match ends puts back what was there before. Generic: paintball can use it too.
2. *A new world per match.* Clean, but creating and unloading worlds stalls the server.
3. *Five hand-built boards.* No core change, but five maps to keep in sync and a hard limit.

**Saving** (picked: one YAML file per unfinished game, `plugins/Chess/games/<id>.yml`), written off
the main thread after every move. The moves are stored as UCI text and replayed on load.

**Clicking** (picked: ray to the board plane). The look ray from the eye meets the board's top
surface; the hit point gives the square. No entities to click, works from any distance.

## 4. What was built

- **`chess/` plugin (Chess.jar)**, depends on MinigameCore.
  - `rules/`: plain-Java chess (Position, GameRecord, ChessClock, BoardGeometry), tested with the
    standard perft counts (start position to depth 4, Kiwipete, positions 3–6): castling, en passant,
    promotion, pins, checks. Mate, stalemate, threefold repetition, 50 moves and too little material
    end the game automatically. Losing on time against a bare king or king plus one minor piece is a draw.
  - Modes = time controls from config: `chess:snel` 5+3, `chess:normaal` 15+10, `chess:vrij` no clock.
    The clock starts once both sides have moved.
  - Pieces: pack item models on item displays, glide when moved, captured pieces spin away. Move
    markers (green move, red capture) and the hover square are seen by the player to move only; last
    move (yellow) and a king in check (red) are seen by both.
  - Hotbar: pick (left or right click anywhere), offer/accept draw, pause, resign (two clicks).
    Promotion opens a 4-piece menu.
  - `/schaak` (alias `/chess`): unfinished games menu; click to invite the opponent (clickable
    **[Doorgaan]**, 60 s), shift-click twice to delete. Also reachable from the chess modes menu.
- **MinigameCore additions** (general, not chess-specific):
  - `ArenaDefinition.copies`, `ArenaCopies`, `ArenaCopier`, pool support, `/mg arena copies <n>`.
  - `MatchOutcome.paused(...)`: ends without a result.
  - `MatchHandler.keepsRunningWhenAlone()`, `MatchContext.rejoin(player, team)`.
  - `MatchStarter` service: a game starts a match for chosen players (used to continue a game).
  - `GameType.teamName`, `coreText` (core titles in the game's words), `queueBlock`, `menuEntry`.
- **Resource pack:** 12 Staunton piece models (boxwood and walnut, turned as regular octagons),
  generated by `tools/pack_src/chess.py`.
- **Map:** `tools/maps/schaakwoud.py`, board 3×3 blocks a square on a timber plinth in a forest
  clearing, a timber stand 14 blocks up behind each side (front rows glass so the near ranks show).
  Template at x 3000, z 3000. Arena file with `copies: 5`.

## 5. Arena marks

`flag 0` = centre of a1 and `flag 1` = centre of h8, on the board's top surface; `spawn 0` = white's
stand (must be on the rank-1 side), `spawn 1` = black's. The plugin derives square size and direction
from these and logs a warning if a1/h8 are mirrored.
